## Featured work

### [EqLume](https://github.com/gokturkgocen/EqLume)
Free, open-source system-wide equalizer for macOS that detects each track's
genre and applies a matching EQ preset. Menu bar app on a Core Audio process
tap — no virtual audio driver, no kernel extension.

### [WhaDay](https://github.com/gokturkgocen/WhaDay)
Native SwiftUI iPhone app that turns each calendar date into a reason to text
someone.

### [safe-compact](https://github.com/gokturkgocen/safe-compact)
Claude Code plugin: auto-compaction waits until Claude writes a handoff note,
and the note comes back verbatim afterwards.

### [RedditRadar](https://github.com/gokturkgocen/RedditRadar)
Read-only Reddit scanner that surfaces posts worth answering. It cannot post,
comment or vote.

### [yolo_eye_security](https://github.com/gokturkgocen/yolo_eye_security)
YOLOv8 person-detection prototype with local-network status/snapshot endpoints
and mobile-client integration.
